KIANA’S PROMISE — VERSION 3.1 MOBILE EDITION

Extract all files together. Open index.html for desktop demo. For local PWA testing, open a terminal in this folder and run python -m http.server 8000, then open http://localhost:8000. For iPhone testing, deploy all files to an HTTPS static host (private preview recommended); open the resulting URL in Safari and use Share > Add to Home Screen. A LAN HTTP address is not sufficient for service worker testing. No hosting has been configured.

Use fictional records only. Authentication, payments, signatures, Teams and document metadata are simulated; owner access is unprotected. Local storage is device/browser/origin specific and is not synchronized. V3 storage key is retained, but records only carry over if the browser uses the same origin/storage context. Home screen mode may have separate storage. Offline support caches the application shell, not a server database. No actual device or App Store testing performed. Existing 30-minute booking start increments retained.

Test on Safari iPhone/iPad, Chrome Android and desktop: enrollment, approval, placement, booking, cancellation, reviews, rotation, keyboard, home screen installation and offline reload. Do not use for real families until secure backend and privacy review are complete.
